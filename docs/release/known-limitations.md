# v0.3.1 公开预览 · 已知限制

更新：2026-10-11（北京时间）。对应版本：桌面端 0.3.1-preview / 核心 0.3.1a1。逐项状态见 [v1-inventory.md](v1-inventory.md)。

## 交付

- **不推送、不开 PR、不回帖 Issue。** 任务结束只在你的仓库里生成本地分支 `tw/<run_id>`，在运行目录（`~/.triwitness/runs/<run_id>/`）生成 `pr.md`（PR 说明 + 证据包）和 `patch.diff`。结论卡上的按钮是“复制 PR 说明”和“打开运行目录”，推送和开 PR 需要你自己做。计划在 v1.0 支持“审批后推送并开 PR”。
- 不监听 CI，也不会根据 CI 结果返工。

## 模型与费用

- **需要你自己的 DeepSeek API 密钥**，从 0.3.1 起没有演示模式：每条消息（包括“你好”）都是一次真实调用，计入本机账本。直接回复通常不到 ¥0.001；修复任务通常 ¥0.05–0.30。
- 对话轮由模型判断“直接回答还是动手”，判断错时（比如把提问当成要修改）它会转成任务；任务每一步仍受权限模式约束，不会静默改代码。
- 多轮历史只带最近 20 轮的用户原话和回复摘要（不带之前各轮的工具输出）。

## Agent

- 只有 **Executor 单角色** + 确定性复验（复现测试、回归、防作弊、风险分级）。Planner / Reviewer 角色、计划级确认、返工回路都还没做。
- 不支持断点续跑：任务中途关掉应用，下次只能重新开始（已产生的工作区 / diff 会保留）。
- 只支持 DeepSeek `deepseek-flash`；Qwen / GLM、跨厂商互审在界面上是灰的。
- 修的主要是 **Python 仓库**（复现测试、相关测试选择、静态检查都按 Python 做）。其他语言能改代码，但验证会弱很多。

## 环境（Windows）

- 需要 **Git for Windows**（工作区、命令执行都靠它；没有 Git Bash 时退回 PowerShell）。
- 内置核心不含你项目的依赖：跑测试用的是**你项目自己的 Python 环境**（在仓库里能 `python -m pytest` 才行）。ruff / pyright / bandit 没装就跳过对应检查，结论卡会标出来。
- 沙箱：默认“无沙箱”（本机 + 独立 git worktree + Job Object），结论会标“干净环境未验证”。Docker 后端可用但需要你自己装 Docker Desktop；**设置里的一键安装 Docker / WSL2 在 Windows 真机上还没完整走通过**，重启后的续装也没做。WSL2 后端未做。
- **没有代码签名**：SmartScreen 会拦“未知发布者”，点“更多信息 → 仍要运行”。
- **没有自动更新**：“检查更新”只打开 GitHub Releases 页面。
- 只有 x64 NSIS 安装包，没有 MSI、ARM64、macOS / Linux 版。

## 验证覆盖

- 真实模式（DeepSeek）在**命令行**下跑过约 3000 次调用（评测）；0.3.1 的对话轮 / 多轮 / 任务流程在 CI 和本机用**本机模拟服务**（真实适配器 + SSE）端到端跑通，**用真实密钥从桌面应用发起的运行还没有做**，审核模型（模型自动审批）也还没真实调用过。第一次用真实模式时，建议先用一个小仓库、把单任务上限调到 ¥0.30。
- 以下只在 CI（windows-latest）或 Linux 上验证过，**还没有在用户 Windows 真机上逐项验证**：Windows 凭据管理器存密钥、原生文件夹对话框、Git Bash 执行、完全访问模式、`tw doctor`、高 DPI / 多显示器。
- Win11 Snap Layouts（悬停最大化按钮出布局）不支持。

## 界面

- 标“即将推出”的入口：语音输入、“+”菜单里的截图 / 网页搜索 / 深度研究 / 技能 / 连接器 / 插件、更多模型、连接器（GitHub / GitLab / Gitee）、帮助。点了只提示，不会做任何事。
- 分享只支持本机导出（Markdown / PDF），没有云端链接。
- 完整证据页还没做，只有结论卡 + 作品栏里的 pr.md / patch.diff。

## 隐私与成本

- 不收集遥测、没有崩溃上报。数据（会话、账本、运行目录、权限规则）都在本机 `~/.triwitness`；API 密钥只存在 Windows 凭据管理器里。
- 真实模式按 DeepSeek 官方价计费（高峰 2×，默认拦下）；单任务上限默认 ¥1.00，只能调低。

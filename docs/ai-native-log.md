- 2026-10-11｜v0.3 安装包冒烟：Windows 卡死排查｜CI 上静默安装后，安装目录里的 tw.exe 跑演示会在第一个事件前卡住，构建目录里的同一个 tw.exe 却正常。AI 先怀疑安装路径，加了诊断：比对两份文件（762 = 762）、分别在 Git Bash 和 PowerShell 下冒烟、打包入口支持 `TW_HANG_DUMP_S` 定时打印所有线程调用栈。结果 Git Bash 通过、PowerShell 卡住，所以问题出在环境，跟安装路径无关。调用栈显示卡在 `find_shell → git --exec-path`：PowerShell（和桌面端）里 PATH 上的 git 是 `Git\cmd\git.exe` 启动器，超时后 `subprocess.run` 只杀掉启动器，孙进程还握着 stdout 管道，Windows 上 communicate() 等读线程永远不返回，`timeout=5` 形同虚设。修法：先从 PATH 上的 git 路径和 Program Files 推出 bash.exe，最后才起子进程；起子进程时输出写文件、stdin 为空、超时杀整棵进程树（`run_quiet`）。PowerShell 冒烟留在 CI 里，因为它最接近桌面端的环境。人工判断：Git Bash 下的测试再绿，也不能代表用户机器的环境。¥0。

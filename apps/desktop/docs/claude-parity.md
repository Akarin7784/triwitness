原则：操作方式与 Claude Desktop 一一对应，不缺也不多。差异只放在审美和复验功能上。

状态：**done** 已可用 · **stub** 入口在，点了提示即将推出 · **todo** 还没有入口

最后更新：2026-10-11（UI-21 第 3 轮 + 界面审查）

# 界面全面审查 · 2026-10-11（UI-21 第 3 轮之后）

工具：`tools/shoot-review.mjs`（真实核心 · 演示适配器 · ¥0）。共跑 4 遍：浅色、深色、English（浅色）、减少动态效果。截图在 `docs/review/`，文件名是 `<遍>-<序号>-<状态>.jpg`，1440×900，窄窗口另拍 960×640。

覆盖的页面和状态：空会话、演示会话、+ 菜单、模型菜单、审批卡、任务结果、作品栏（补丁 / pr.md）、标题菜单、分享、搜索面板、快捷键表、侧栏收起、会话 … 菜单、风格菜单和风格对话框、项目页（空 / 新建 / 详情）、作品页、设置 9 个分区（长分区另拍滚到底）、勇士模式确认、开源许可、清除记录确认，以及窄窗口。

每个状态自动检查以下几项：
- 文字溢出：单行文字超出容器，且没有截断。
- 出界：元素露出窗口右侧，且没有被祖先裁剪。
- 文字对比度：按 WCAG 计算。会叠加透明度和背景层；小字门槛 4.5，大字 3。
- 键盘焦点：从页首按 Tab 28 次，看每个焦点有没有可见的焦点指示。
- 中文字体和行高。
- 动画帧间隔：在动作期间记录 rAF 帧间隔。
- 减少动态效果：菜单多久稳定、CSS 动画是否被关掉。

## 保持原样（测过，没有问题）

- **溢出和出界**：浅色、深色、英文、窄窗口共 139 张截图，0 处溢出，0 处出界。英文更长的文案也都能换行或截断。
- **键盘焦点**：前 28 个可聚焦元素都有可见的焦点指示。唯一例外是输入框，靠光标和输入框本身表示焦点，和 Claude 一致。
- **中文排版**：
  - Noto Serif SC 和 Noto Sans SC 都已加载。
  - 输入框是宋体 15px，行高 1.63。
  - 正文 `.md` 是 14.5px，行高 1.85。
  - 侧栏是黑体，行高 1.5。
  - 没有额外字距。
  - `<html lang>` 会跟着语言切换（zh-CN / en）。
- **动画帧间隔**：headless Chrome 软件渲染，60Hz。
  - 打开 + 菜单：p95 16.7ms，0 帧超过 33ms。
  - 切换设置分区：p95 16.8ms，0 帧超过 33ms。
  - 流式输出：p95 16.8ms，偶有 1–3 帧超过 33ms。
  - 打开作品栏：p95 16.7ms。第一帧 66–83ms，是挂载面板和渲染 diff 的一次性开销。
  - 收起侧栏：p95 33–50ms，2–3 帧超过 33ms。原因是宽度弹簧动画加上会话列表的挂载和卸载。软件渲染下数字偏高，真机 GPU 合成会好得多。已记为后续可以优化的点（列表改成淡出而不是卸载）。
- **减少动态效果**：
  - CSS 动画被压到 1ms（`.fade-in` 实测 0.001s）。
  - framer-motion 由 `MotionConfig reducedMotion="user"` 去掉位移和缩放，只保留淡入；+ 菜单 243ms 内稳定。
  - 墨晕效果关闭。

## 仍然低于 AA 4.5、但有意保留的

- 浅色下的次要小字：4.15–4.37（见第 4 条）。
- 鼠尾草绿（3.2）和朱砂色（3.24）的小标签，比如“允许”“例外”“空闲”、diff 的 +/− 计数、勇士模式标题。这些都是状态色，旁边有图标或文字一起表达意思，不是只靠颜色区分。
